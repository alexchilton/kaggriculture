## Step 1 — widen the routing table, fitted on a frozen field

**Mechanism.** `SHOP_PLANS` keys only on worlds containing a YARN_STORE. Every other world falls through to the default plan 0. *Measured:* forcing all 13 tapes over 16 seeds and both seats, against the parent, the four largest regrets are all fall-through worlds -- `PET_CAFE|BRUNCH_SPOT` $13,842 (plan 11 wins), `PIZZA_SHOP|PET_CAFE` $12,746 (plan 8), `PET_CAFE|BRUNCH_SPOT` $12,390 (plan 12), `PET_CAFE|PIZZA_SHOP` $8,187 (plan 8). On 7 of 16 seeds a tape **already in the bundle** turns a tie into a win. Rows in `data/logs/plan_regret.csv`.

**What this is not.** The opponent in that run was the parent itself, so the rule's pick always mirrors and always scores zero. A mirror is not a best response, and the number above is a bound against one opponent, not a field result.

**Work.** Build a frozen field -- the 13 tapes as 13 distinct opponents, our own planner bundle, and `raykkretzschmar/kaggriculture-reference-agents` -- then run 13 tapes x 16 seeds x field x both seats and take, per world, the tape with the best **win rate**. Write the result as a new table in an overlay module. `router_parent.py` stays byte-identical so `scripts/build_imported_submission.py` keeps verifying its published hash.

**Cost.** About 2,500 games at roughly 2 s each across 5 workers: 20 to 30 minutes.

**Gate.** The new table must beat the published table on win rate over a **fresh draw of seeds it was not fitted on**. A fitted-seed win alone is the winner's curse; this repo has already paid for that lesson once. If held-out win rate does not move, revert the table and put the number in the commit message.
